# Ecommerce webapp

This repository contains a small frontend ecommerce/demo web application (dashboard, orders, payment pages). Display name: "Ecommerce webapp". Repository slug (recommended): `ecommerce-webapp`.

Quick notes

- Project type: static frontend (HTML/CSS/JS)
- Entry file: `index.html` (open in browser or serve from a local static server)

Run locally

Using Python (if installed):

```powershell
python -m http.server 8000
# then open http://localhost:8000 in your browser
```

Using Node (no install required if you have npm):

```powershell
npx http-server . -p 8000
# or
npx serve . -p 8000
```

Project structure (top-level)

- `index.html`
- `js/` — JavaScript files (app logic)
- `pages/` — HTML pages for dashboard, orders, payments
- `css/` — styles
- `import&export/` — example import/export utilities
